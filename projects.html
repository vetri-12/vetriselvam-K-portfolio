Custom B2B ERP — Facade, Glass & Construction Industry

Laravel 11 • Filament PHP v3 • Livewire • Tailwind CSS • AI-Assisted Development

Designed and deployed a production-ready custom B2B ERP solution to manage business operations, project workflows, and financial tracking for a client in the facade and construction industry.

  • Business Analysis & Architecture: Defined business workflows, functional requirements, module structure, and system architecture based on operational challenges.
  • Module Implementation: Implemented multi-tenant structures managing Account Master, Product Master, Purchase Orders, Work Orders, Fabricator Measurements, and Delivery Challans.
  • AI-Assisted Development: Worked iteratively with AI development tools to generate, review, refine, and troubleshoot application code while maintaining a secure private Git repository.
  • Workflows & Reporting: Designed transactional workflows, financial calculations, dashboard reports, PDF document generation, and Excel data exports.
  • Testing & Deployment: Conducted comprehensive functional testing and supported live implementation and client workflow validation.
